# 待办入口改造 · 原型说明

> 状态：**已按「顶部按钮 + 下拉面板」实现（v0.2.0）并通过 GUI 验证**。
> 原型文件：`dropdown.html`（`?state=open|closed`），截图 `dropdown-open.png` / `dropdown-closeup.png` / `dropdown-closed.png`。
> 上一版「输入框胶囊 + 右下浮窗」保留为设计备选：`index.html` / `mock-*.png`。

## 为什么要改

1. **右侧栏太大。** 现版本把待办做成右侧栏的整栏页签（约 600px 宽、整列高），短清单占地方，还会把对话挤窄。
2. **已创建的会话没有可见入口。** 现版本只有空白新会话的 Hero 提示和右侧栏 Guide 入口；已有会话默认不展开右侧栏，也没有常驻按钮，所以「看起来无法创建待办」。数据上并没有限制：任何会话都能读写项目根目录的同一份 `.todo.md`。

## 当前方案：顶部按钮 + 下拉面板

### 位置

- **入口按钮**放在会话标题栏右上角的操作区（`conversation.session.header.utilities`，与「会话历史 / 更多」同一排），任何已创建会话都常驻可见。
- 按钮形态：清单图标 + 「待办」+ 进度 `1/3` + 下拉箭头；面板展开时按钮为激活底色、箭头旋转。
- **下拉面板**从按钮下方展开、右对齐，宽 348px；避开标题栏按钮、不遮挡输入框。面板用 portal 挂到 `document.body` 并用按钮的 `getBoundingClientRect()` 定位，避免标题栏裁剪。

### 面板内容

- 头部：清单图标、标题「待办清单」、进度、`AI 分析` 按钮、收起 `×`。
- 进度条：2px，完成比例。
- 列表：复选框 + 文本；已完成置灰 + 删除线；悬停行尾出现删除；点击文本行内编辑。
- 底部：添加输入框（回车新增）+ `.todo.md` / Git 状态。

### 交互

| 行为 | 规则 |
|---|---|
| 展开 / 收起 | 点顶部按钮切换；点面板外或按 Esc 收起；`×` 也能收起 |
| 状态 | 不拖动、不最小化、不持久化——按钮本身就是收起态，每次载入默认收起 |
| 新会话提示 | 空白会话 Hero 轻提示保留，点击直接展开下拉面板 |
| 所有会话 | 按钮常驻标题栏，不需要右侧栏、不需要额外入口 |
| 窄窗口 | 宽 < 768px 时面板宽度 `calc(100vw - 24px)`，右对齐视口 |
| 数据同步 | 仍以 `.todo.md` 为唯一事实来源；面板打开时轮询外部修改，编辑/保存时暂停 |
| 发送给 AI | 面板头部「AI 分析」；消息形态与现版本一致 |

## 不改的部分

- `.todo.md` 格式、任务行原地重写、标题/注释保留。
- Git 行为：工作树内首次保存 `git add`，不自动 commit；被忽略时告警。
- 发送给 AI 的提示词与会话消息形态。
- Host 侧三条同源路由与安全校验。

## 实现映射（v0.2.0）

| 关注点 | 实现 |
|---|---|
| 按钮 | `conversation.session.header.utilities`（list，session scope），order 10，右对齐工具区 |
| 面板宿主 | `conversation.input.overlay`（list，session；Hero 状态也挂载），`createPortal(document.body)` |
| 共享状态 | 模块级 store：`{ open, sessionId, anchor, trigger }`；按钮/提示打开，宿主渲染，Esc/外部点击关闭 |
| 定位 | `getBoundingClientRect()` + `position: fixed`；resize/scroll 重算并 clamp |
| 新会话提示 | `conversation.hero.options`，点击打开同一个面板 |
| 数据 | 仍走 Host 的 `load` / `save` / `send` 三条同源 JSON 路由，文件格式不变 |

## 与上一版（右下浮窗）的区别

| | 右下浮窗 | 顶部按钮 + 下拉面板 |
|---|---|---|
| 入口位置 | 输入框工具栏 | 会话标题栏 |
| 面板位置 | 右下角浮动 | 按钮下方下拉 |
| 收起形态 | 标题条 | 按钮本身 |
| 拖动/记忆位置 | 有 | 不需要 |
